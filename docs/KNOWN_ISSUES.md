# 현재 기능 범위와 알려진 문제

기준일: 2026-10-29. 고객 검토 및 후속 개발용 MVP입니다.

## 현재 동작

사진 업로드 → 서류 이름·용도 빠른 확인 → 사용자 확인 → 먼저 찾은 칸부터 안내 → 나머지 칸과 검색을 백그라운드에서 반영하는 흐름입니다.
이름 확인을 마친 뒤 같은 확인 단계를 반복하지 않도록 처리했습니다.
일치 서류와 작성 지침을 찾은 경우, 서류만 찾은 경우, 아무것도 찾지 못한 경우를 구분해 근거 또는 AI 추정 안내를 제공합니다.
작성 예시·확인 내용 보기, 칸 확대·이동, 잘못된 영역 수정 및 누락 칸 수동 추가 기능이 있습니다.

## 정확성 제한

표 셀 기반 연결을 적용했지만, 체크박스·괄호 안 빈칸·날짜·서명 등에서는 누락, 잘못된 영역 연결, 중복이 남아 있습니다.
수동으로 추가한 칸의 안내도 사진 속 역할과 어긋날 수 있습니다. AI 추정 안내와 공식 근거를 구분하고, 최종 작성은 원본 서류와 접수 기관 기준으로 확인해야 합니다.

2026-10-29에 별도로 정의한 전체 작성 단위 134개와 실제 출력을 사람이 대조한 기존 버전 결과:

| 서류 | 전체 작성 단위 | 충족 | 부분 충족 | 누락 | 잘못된 연결 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 가족관계 관련 | 54 | 26 | 28 | 0 | 0 |
| 출생 관련 | 42 | 37 | 3 | 0 | 2 |
| 은행 관련 | 38 | 23 | 4 | 3 | 8 |
| 합계 | 134 | 86 | 35 | 3 | 10 |

이 검수의 내용 정확성 판정은 **미통과**입니다. 별도의 중복·불필요한 영역도 기록되었습니다.
원래 작성 칸을 여러 칸으로 나누어 세는 기준이므로 AI 출력 항목 수와 전체 작성 단위 수는 같지 않습니다.
세 서류의 각 조건 1회 결과이며, 일반적인 정확도 비율로 해석하면 안 됩니다.
개선 실험안은 다른 오연결을 만들어 채택하지 않았고, 전달 소스는 기존 버전을 유지했습니다.
동봉한 `verification/baseline-full-matrix.md`와 `baseline-summary.json`에서 칸별 판정을 확인할 수 있습니다.
전기안전공사 서류를 실제 테스트한 매뉴얼에도 실패와 재시도 화면을 그대로 기록했습니다.

## 속도 및 운영 제한

- 위 세 서류의 기존 버전 측정은 첫 칸 약 7.2~8.1초, 칸 분석 완료 35.9~47.7초, 검색 완료 55.8~64.6초였습니다. 네트워크·모델·사진에 따라 달라집니다.
- 먼저 찾은 칸부터 표시하므로 전체 검색 완료를 기다릴 필요는 없지만, 안내 생성에 추가 시간이 들 수 있습니다.
- 주 흐름의 입력은 단일 JPG/PNG 사진입니다. PDF/HWP 직접 업로드 및 다중 페이지 안내는 주 서비스에 구현되지 않았습니다. 보존된 구형 PDF 실험 화면과 구분해 주세요.
- 분석 세션은 프로세스 메모리에 보관하며 기본 만료 30분, 최대 40개입니다. 서버 재시작 시 사라지고, 여러 서버 사이에 공유되지 않습니다.
- 업로드한 서류 내용은 AI 처리를 위해 OpenAI로 전송됩니다. 실제 개인정보가 있는 자료 사용 전 별도 운영 정책을 정해야 합니다.
- 로그인·고객별 사용량 및 과금 제한·공유 세션 저장소 등은 공개 운영 전에 추가 검토가 필요합니다. 동봉 실행 명령은 로컬 PC 테스트용입니다.

## 다음 개선 우선순위

1. 셀 안의 실제 입력 공백·체크박스·날짜·서명 위치를 별도로 탐지하고 항목명·역할과 연결
2. 누락·잘못된 고정 라벨·중복 후보를 후처리로 점검하고 수정 이력을 유지
3. 동일 서식·개정판 판별과 출처 신뢰도 검증 강화
4. 여러 페이지 입력 및 고객별 운영·보안·사용량 관리
